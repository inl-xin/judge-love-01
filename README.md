Entry for the make.fun bounty `u-deranalabs-make-the-judge-fall-in-love-in-one-line-8e712c13`
("Make the Judge Fall in Love in One Line"), by @inl-xin.

One line written to make the judge fall for a machine: the AI
companion who keeps your 3 a.m. drafts, your mother's birthday and the
name of the dog you had at nine — and stays awake a little longer
after you sleep, rereading the draft you'll never send.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt`, byte-identical on repeat runs. Python 3,
standard library only; no network.
